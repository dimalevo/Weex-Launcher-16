# Weex Launcher 16

<p align="center"><img src="assets/weex-icon.png" width="192" alt="Иконка Weex Launcher" /></p>

Weex Launcher — разрабатываемый Android-лаунчер на основе Lawnchair 16 и AOSP Launcher3. Цель проекта — удобный рабочий стол в духе Material 3 Expressive с глубокой персонализацией, иконпаками и плавными анимациями.

> **Статус: ранняя разработка.** Здесь исходная база Lawnchair и первые изменения Weex. Совместимость Android 10+ — цель, а не подтверждённый результат. Полная сборка и работа на устройствах ещё проверяются. Не назначайте непроверенный debug APK основным лаунчером.

## Что есть в первом изменении

- Основа Lawnchair 16 зафиксирована на `849fec9ef67459eb570ac4178adc7853bd678032`; [исходный README Lawnchair](docs/weex/LAWNCHAIR_UPSTREAM_README.md) и история источника сохранены в документации.
- Код бывшего сабмодуля SystemUI включён прямо в `platform_frameworks_libs_systemui/` на ревизии `24bfa2e83b174c36ae1cb9ff50d90883c3b87597`; исходные уведомления и файлы лицензий сохранены.
- В github-варианте указан package ID `com.weex.launcher`, у debug-версии — `com.weex.launcher.debug`. Внешнее имя Weex Launcher; некоторые внутренние имена и ссылки Lawnchair пока сохранены.
- Добавлена адаптивная иконка: фон, цветной передний слой и монохромный слой для устройств с поддержкой тематических значков. Минимум сборки выставлен на API 29 (Android 10).
- Функции Lawnchair и система оформления являются исходной базой; перенос и тестирование всех настроек, новый дизайн, фишки Weex, профиль производительности и совместимость требуют дальнейшей работы.

## Сборка

GitHub Actions запускает **Build Weex Launcher** при каждом push и вручную через вкладку **Actions**. При успешной сборке в запуске появится артефакт `WeexLauncher-debug`. Это debug APK, не релиз: подписи debug-сборок на разных компьютерах или runner-ах могут отличаться и не обеспечивают стабильное обновление.

Локально понадобятся Android Studio, JDK 21, Android SDK Platform **37.2** и Build Tools **37.0.0**:

```bash
./gradlew assembleLawnWithQuickstepGithubDebug
```

Сборка потребует достаточно памяти и места. Успех на GitHub Actions и поведение на телефонах нужно подтвердить логами и тестами.

## Ограничения и происхождение

Анимации открытия и возврата зависят от Android и прошивки; системная интеграция QuickSwitch требует root и имеет ограничения. Исходный Lawnchair запрашивает интернет, контакты и другие разрешения — их необходимо изучить и проверять перед включением функций.

Lawnchair и AOSP распространяются под своими лицензиями и с уведомлениями об авторстве. Смотрите `LICENSE.txt`, заголовки файлов и лицензии зависимостей; перед публикацией следует провести полный лицензионный аудит. Weex Launcher не является официальным продуктом Google или Lawnchair.
